Data definitions, missing values & provenance

The default type priority is SPIFFStacker → SUBLIME aperture → latest SUBLIME2 candidate autotype → SPIFF → public spectroscopic type. Each lane uses its newest non-ignored stored type. The spectrum panels refit the latest active spectrum, so a newly computed best fit can differ from the stored type used for sorting.

Known means a public-adopted nonphotometric M0+ spectral type, including confirmed duplicate links. Use “Recovered known” for public L0+ types. This is a spectral definition, not a mass confirmation. The unpublished population can include unconfirmed candidates.

BYW claims combine the Schneider BYW claimlist with BYW discoverer names containing yadu, tom, bickle, sarah, azul or eastonh, following the reviewer's claim rules. Yadu and Azul memberships remain separate controls. SMDET checks registered designations.

Absolute magnitudes use M = m − 5 log₁₀(d / pc) + 5. Positive adopted parallaxes take priority, followed by adopted nonphotometric distances. Photometric distances are optional and marked separately. They can make a type–magnitude diagram circular. Synthetic W2 comes from stored SPHEREx-linked photometry (or the explicit spherex_w2_synth method), with its measurement and spectrum IDs in CSV. No missing synthetic measurement or distance is inferred.

Blank numeric cuts keep missing values. An enabled cut requires a measured value. Cutout cuts apply to reviewed cutouts only; “all” requires every stored review to pass, and “any” requires at least one. Unreviewed images are not implicitly good. Duplicates remove only the potential_duplicated_moca_oid side of confirmed “y” pairs; inactive objects are always excluded.
